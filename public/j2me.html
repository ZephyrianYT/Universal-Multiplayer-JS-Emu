📱 Phone games (J2ME)

Play old Java phone games (.jar, sometimes with a .jad) in this browser with freej2me-web. Games open in a new tab.

Needs internet: the emulator runs on CheerpJ, a Java runtime that your browser downloads from cjrtnc.leaningtech.com (Leaning Technologies) each time. That site sees your IP address, like any website. Your game files are not sent to it.
📲 Load a .JAR Opens the phone game launcher: add a .jar from your computer, set the screen size and phone type, and it stays installed in this browser with its saves. Hub games you've played show up there too (to change their settings).
