🖥️ PC: DOS and Windows 9x

An emulated 90s PC in this browser (v86). Boot a disk image with DOS or Windows 95/98 on it, and put game CDs in while it runs. Your files stay on your computer: nothing is uploaded, and the PC has no internet.

Tips

  • Click the screen to type into the PC. 🔒 Mouse captures the mouse for Windows (Esc lets go).
  • Snapshots: once Windows is on the desktop, 💾 Snapshot saves the whole PC to a file. Next time load it under “Resume a snapshot” together with the same disks and memory, and you're back in a second or two.
  • Windows 95/98 tips: install the VBE9x (VBEMP) display driver for more colors and 800×600+; Windows 95 needs the FIX95CPU patch on fast CPUs.
  • Adding a game: CD games: make an .iso of the game folder (ImgBurn, Folder2ISO, mkisofs) and use 💿 Game CD. Installed games: copy the folder into your .img with 7-Zip or WinImage first.
  • Snapshots and changes to disks live only in this tab: save a snapshot before closing or they're gone.
  • Hub owner: one folder per PC/game in roms/x86 (e.g. roms/x86/Windows 98/win98.img + game.iso); a .v86state there is resumed automatically.
