🗝️ ScummVM

Classic point-and-click adventures (LucasArts, Sierra, Revolution and hundreds more) in this browser with ScummVM. Games open in a new tab; saves stay in this browser.

The first start downloads ScummVM (about 45 MB, plus each game engine the first time it's used) to the hub, then it's quick.

No ScummVM games on this hub yet.

Open ScummVM's launcher ScummVM's own menu: options, saved games, and Add Game… for any hub game folder.

Hub owner: put each game in its own folder in roms/scummvm (for example roms/scummvm/Flight of the Amazon Queen/) with all its data files inside, the way you'd copy it for ScummVM. A cover.png in the folder becomes its picture. ScummVM can't open folders from a player's own computer in the browser, so games go on the hub. Free games: scummvm.org/games.
