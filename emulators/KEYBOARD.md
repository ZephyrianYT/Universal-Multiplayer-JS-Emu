# Keyboard mode: guest key layout

When neither virtual-gamepad option is installed (vgamepad + ViGEmBus on Windows), Retro Hub falls back to
**keyboard mode**, which needs no installs. Each guest seat gets its own keys, pressed with Windows' own
`SendInput`. Bind these keys **once** in each emulator's controller settings for ports 2, 3 and 4.

- Keys are sent **only while the focused window belongs to a program inside the `emulators/` folder**.
  Guests can't type into your browser, chat or anything else. Click the emulator's game window after you share it.
- Sticks are 8-way digital in this mode (pressed past half-way). Triggers are on/off.
- Clear the keyboard bindings from **port 1** (many emulators bind the keyboard to port 1 by default),
  or guests will also move your character.
- Keep **Num Lock on** for P4.
- F-keys, Esc, Tab, Space, Enter, Backspace and modifier keys are never used: emulator hotkeys stay yours.
- To force a mode, set `NATIVE_INPUT=keyboard` or `NATIVE_INPUT=gamepad` in `.env` (default `auto`).
